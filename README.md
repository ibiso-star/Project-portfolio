# Project Portfolio

## Regional Clinical Access & Capacity Transformation — interactive case study

`index.html` is a self-contained, interactive executive dashboard (no build step, no dependencies beyond Google Fonts).

**View it:** open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → deploy from branch, root folder).

### What's interactive
- **Headline figures** link to the section that explains them.
- **Tabs** (Challenge · CBAP strategy · PMP governance · Returns) with shareable links, e.g. `index.html#returns`.
- **Stakeholder map** and **CBAP step-through** (align → elicit → define → decide).
- **Risk register** with filters and expandable responses.
- **Payback scenario explorer**: adjust investment, benefit realization, ramp-up and horizon to see payback, net position and ROI, with a 50%–120% sensitivity band.
- Light/dark theme, responsive down to phone width.

### Updating the figures
All numbers and text lists live in the `CASE` object at the top of the `<script>` in `index.html`. Replace them with your own substantiated evidence.

> **Use with integrity:** every named organization, figure and event in this case study is fictional and illustrative. Secure permission before naming organizations, and distinguish actual savings from cost avoidance and estimates.
